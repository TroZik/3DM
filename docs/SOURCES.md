# Sources des données

## Manuel atelier (source principale)

VW Workshop Manual « 4-cyl. injection engine (1.8 and 2.0 l engine, chain drive) », édition 08.2018.
Codes moteur couverts : CAWA, CAWB, CBFA, **CCTA**, CCTB, BZB, CGYA, CCZA, CCZB, CCZC, CCZD, CDAA, CDAB.
Version consultée en ligne : https://workshop-manuals.com/volkswagen/golf-mk6/power_unit/4-cylinder_injection_engine_(1.8_and_2.0_l_engine_chain_drive)/

Sections utilisées :

| Domaine | Section du manuel |
|---|---|
| Culasse, vis de culasse, reniflard, pompe à vide | Assembly overview – cylinder head |
| Carter d'arbres à cames | Assembly overview – valve gear |
| Carters de distribution | Assembly overview – timing chain covers |
| Distribution, arbres d'équilibrage | Camshaft timing chain / Balancer shaft timing chain |
| Carters d'huile, séparateur | Assembly overview – sump, oil pump |
| Paliers de vilebrequin | Assembly overview – crankshaft |
| Bielles | Assembly overview – pistons and conrods |
| Poulie, support d'accessoires | Assembly overview – poly V-belt drive |
| Flasque, volant bimasse | Sealing flange on gearbox side and dual-mass flywheel |
| Filtre et refroidisseur d'huile, F1 | Oil filter, engine oil cooler and oil pressure switch (CCTA) |
| Pompe à eau, thermostat | Coolant pump and thermostat – exploded view |
| Turbo, collecteur | Turbocharger – parts I à IV, removing and installing |
| Admission, pompe HP | Assembly overview – intake manifold, fuel rail |
| Capteurs, bougies | Assembly overview – ignition system |
| Supports moteur | Assembly overview – assembly mountings |

## Valeurs non disponibles (à compléter)

- Vis de liaison boîte DSG 02E ↔ moteur : dans ELSA, non reprises dans le manuel moteur.
- Vis du démarreur : groupe de réparation 27.
- Vis du refroidisseur d'huile : ordre donné par une figure, couple absent du texte.
- Références pièces (numéros VAG) : catalogue ETKA.

## Notes

- Le manuel est celui de la Golf 6. Le moteur CCTA est identique côté bloc sur l'Audi A3 8P.
- Formes et positions des pièces : modélisation schématique. Les ordres de serrage reprennent la numérotation des figures du manuel.
